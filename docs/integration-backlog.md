## Next organization step

[Issue #7](https://github.com/AsynchronousVentures/scrawl/issues/7) tracks same-space parent/child documents, not a second folder model. [Outline's terminology](https://docs.getoutline.com/s/guide/doc/terminology-fKoXA2YGzH) describes documents as containers for related documents, while its [collection guide](https://docs.getoutline.com/s/guide/doc/collections-l9o3LD22sV) emphasizes collection-level permission boundaries and ordering. Scrawl should keep spaces as the existing permission boundary and readable URLs independent of position. This is a proposed product decision, not implemented behavior.

Core operations must prevent cycles/cross-space parents, serialize concurrent moves under the existing space lock, and require ETags for existing-document moves. Structure belongs to lifecycle metadata rather than immutable content revisions. Preserve all existing root documents, live state, publications and attachment grants. Specify archive behavior before changing persistence; neither archiving nor publishing a parent may silently apply to children. Start with accessible nested navigation and explicit move controls; cross-space moves, drag ordering and permission overrides remain separate work.
