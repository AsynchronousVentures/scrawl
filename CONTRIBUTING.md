# Contributing

This project is early-stage. Start with README.md, docs/plan.md and docs/backlog.md. Discuss a bounded task before expanding the architecture or adding a feature. Existing source is not a production-ready knowledge base.

Unless explicitly identified otherwise, contributions submitted for inclusion are licensed under **AGPL-3.0-only**, consistent with this project's license. Submit only material you have the right to contribute. Contributors retain their copyrights; no copyright assignment or separate CLA is requested by this document. Preserve notices for third-party material and disclose its source/license in the change.

Use synthetic test data, reviewable migrations, explicit public contracts and appropriate success/failure tests. Keep the lockfile current and use frozen installs once established. Do not submit secrets, private documents, dependency directories or database dumps.

For each change, state the assigned packet, behavior added, tests actually run, migration impact and remaining limitations. See docs/agents/working-agreements.md for agent-assisted work.

The repository is named `scrawl`; its public URL and security-contact address have not been supplied. The maintainer must establish a private reporting channel before public release. Do not post exploit details or credentials in a public issue to compensate for that missing setup.
